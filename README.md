# Predictive Maintenance & Machine Failure Analysis Using Python

**Project type:** Data Analysis & Machine Learning
**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Google Colab
**Dataset:** [AI4I 2020 Predictive Maintenance Dataset](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset) (UCI Machine Learning Repository)

## Project Overview

This project analyzes the AI4I 2020 Predictive Maintenance Dataset to investigate industrial machine operating conditions and identify patterns associated with machine failures. It applies data cleaning, exploratory data analysis, statistical analysis, data visualization, and machine learning to show how predictive analytics can support industrial maintenance planning.

## Objectives

- Examine machine failure patterns and operating conditions
- Investigate relationships between temperature, rotational speed, torque, and tool wear
- Identify factors associated with recorded machine failures
- Develop and evaluate a machine-learning classification model
- Explore how data-driven insights can support maintenance decisions

## Methodology

1. **Data preparation:** imported, inspected, and validated the dataset with Pandas
2. **Exploratory data analysis:** analyzed failure rates, machine types, and operating variables
3. **Data visualization:** created charts, box plots, and a correlation heatmap with Matplotlib and Seaborn
4. **Machine learning:** built a Random Forest classification pipeline with Scikit-learn
5. **Model evaluation:** assessed performance using precision, recall, F1-score, ROC-AUC, average precision, and a confusion matrix
6. **Feature importance:** examined which variables contributed most to the model's predictions

## Key Deliverables

- Data quality assessment and prepared dataset
- Exploratory analysis and visualizations
- Machine failure classification model
- Model evaluation results
- Feature importance analysis
- Machine failure prediction output (final table)

The findings illustrate how data analytics can complement engineering knowledge when evaluating equipment reliability.

## Dataset Note

The AI4I 2020 dataset is a synthetic dataset developed for predictive maintenance research. This analysis demonstrates a practical workflow. It does not establish real-world factory performance or prove that failures can be predicted in advance.
